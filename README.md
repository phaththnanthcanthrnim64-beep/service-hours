# ระบบชั่วโมงงานปกครอง

## เทคโนโลยีที่ใช้
- **ภาษา:** JavaScript (Node.js) ฝั่งหลังบ้าน, HTML / CSS / JavaScript ฝั่งหน้าเว็บ
- **เฟรมเวิร์ก:** Express (เว็บเซิร์ฟเวอร์ + REST API), express-session (ล็อกอิน), bcryptjs (เข้ารหัสรหัสผ่าน)
- **ฐานข้อมูล:** MySQL (ฐานข้อมูลเชิงสัมพันธ์ ใช้ภาษา SQL) ผ่านไลบรารี mysql2

## เทียบกับข้อกำหนดโครงงาน
| ข้อกำหนด | สิ่งที่ทำ |
|---|---|
| งานสร้างเว็บไซต์/ซอฟต์แวร์ | เว็บแอปพลิเคชันระบบชั่วโมงงานปกครอง |
| ฐานข้อมูลเชิงสัมพันธ์ ≥ 3 ตาราง | 7 ตาราง: `fields`, `departments`, `levels`, `users`, `activity_types`, `terms`, `logs` (มี Foreign Key 7 เส้น) ดู [ER Diagram](docs/er-diagram.png) |
| หน้าบ้าน / หลังบ้าน | หน้าบ้าน `/` · หลังบ้าน `/admin.html` |
| ตรวจสอบสิทธิ์ 3 ระดับ | admin / teacher / student (ตรวจที่ฝั่งเซิร์ฟเวอร์ทุก API) |
| รายงานข้อมูล | สรุปรายแผนก, รายชั้นปี, ผู้ค้างชั่วโมง, ดาวแดง, พิมพ์รายงาน, ส่งออก CSV |
| เช่า Host และโดเมน | ดูหัวข้อ "นำขึ้นเว็บจริง" |

## หน้าเว็บและความสามารถ
**หน้าบ้าน `/`** หน้าเข้าสู่ระบบ และหน้านักศึกษา
- วงแหวนความคืบหน้า ชั่วโมงที่ต้องทำ / ทำแล้ว / คงเหลือ
- ตารางคำสั่งให้ทำชั่วโมง และชั่วโมงที่ทำแล้ว, ขั้นตอนการทำชั่วโมง
- พิมพ์แบบฟอร์มบำเพ็ญประโยชน์ (`/print.html`) และเปลี่ยนรหัสผ่าน

**หลังบ้าน `/admin.html`** สำหรับครูและผู้ดูแล
- ภาพรวม: จำนวนนักศึกษา, ค้างชั่วโมง, ครบแล้ว, กราฟชั่วโมงรายเดือน 6 เดือน, 10 อันดับค้างมากที่สุด, บันทึกล่าสุด
- นักศึกษา: ค้นหา, กรองตามแผนก ชั้นปี และสถานะ, เพิ่ม (เลือกแผนก + ชั้นปี), **แก้ไขข้อมูล**, **นำเข้าหลายคนจาก Excel** (รหัส, ชื่อ, ชั้นปี, แผนก), รีเซ็ตรหัสผ่าน, ลบ
- รายละเอียดนักศึกษา: ลงชั่วโมง (สั่ง/ทำแล้ว), **แก้ไขรายการ**, ดูผู้บันทึก, กรองประวัติ, พิมพ์แบบฟอร์ม
- **ลงชั่วโมงหลายคนพร้อมกัน** (กรองตามแผนก/ชั้นปี แล้วเลือกทั้งหมดหรือเลือกเป็นรายคน)
- **เหตุผลที่ให้ชั่วโมง**: ตอนสั่งชั่วโมงต้องระบุเหตุผลเสมอ เลือกจากเหตุผลที่ใช้บ่อยได้หลายข้อ (ระบบเติมชั่วโมงแนะนำให้ แก้เองได้) หรือพิมพ์รายละเอียดเพิ่ม
  มีตัวอย่างข้อความก่อนบันทึก เหตุผลเก็บในคอลัมน์ `logs.text` แก้รายการเหตุผลได้ที่ `REASONS` ใน `public/admin.js`
- ลูกเล่นตอนใช้งาน: คลื่นตอนคลิกปุ่ม, ปุ่ม/การ์ดยกขึ้นตอนชี้, ตัวเลขสถิติวิ่ง, แถบความคืบหน้าและกราฟเลื่อนขึ้น, แถวที่เลือกถูกไฮไลต์,
  หน้าต่างเด้งนุ่ม ๆ, ฟอร์มเข้าสู่ระบบสั่นเมื่อรหัสผิด (ปิดให้อัตโนมัติถ้าเครื่องตั้งค่าลดการเคลื่อนไหว)
- **ดาวแดง** (`#redstar`): ถ้าสิ้นภาคเรียนแล้วนักศึกษายังทำชั่วโมงไม่ครบ จะติดดาวแดง และ**ชั่วโมงที่ค้างคูณสอง** (ค้าง 5 → 10)
  - ภาคเรียนเลือกอัตโนมัติจากวันที่ปัจจุบันตามปฏิทิน สอศ.: ภาคเรียนที่ 1 = 16 พ.ค. – 30 ก.ย., ภาคเรียนที่ 2 = 1 พ.ย. – 31 มี.ค.
    (ช่วงปิดภาคเรียนยังนับเป็นภาคเรียนที่เพิ่งจบ เพื่อให้ดาวแดงได้) ระบบสร้างภาคเรียนปัจจุบันและถัดไปลงตาราง `terms` ให้เอง
    ถ้าวิทยาลัยเลื่อนวัน ผู้ดูแลแก้วันของแต่ละภาคเรียนได้ และกดคืนค่าตาม สอศ. ได้ · แก้วันตามปฏิทินได้ที่ `OVEC_TERMS` ใน `server.js`
  - ก่อนสิ้นภาคเรียน: แสดงรายชื่อผู้เสี่ยงติดดาวแดง นับถอยหลังวันในหน้าภาพรวม หน้านักศึกษา และแบบฟอร์ม
  - หลังสิ้นภาคเรียน: ผู้ดูแลเลือกนักศึกษาแล้วกด "ให้ดาวแดง" (ให้ได้ครั้งเดียวต่อคนต่อภาคเรียน, ครูดูได้แต่ให้ไม่ได้)
  - นับเฉพาะชั่วโมงที่ลงวันที่ไม่เกินวันสิ้นภาคเรียน ชั่วโมงที่ทำหลังหมดเขตไม่ช่วยให้พ้นดาวแดง
  - ยกเลิกดาวแดงทีละคนได้ในหน้ารายละเอียดนักศึกษา · กรองรายชื่อ "ติดดาวแดง" ได้ · CSV มีคอลัมน์ดาวแดง
  - ดาวแดง = รายการ `assign` ในตาราง `logs` ที่มี `term_id` (อ้างอิงตาราง `terms`) ชั่วโมงเท่ากับที่ค้าง
- **แผนกวิชา** แบ่งตามประเภทวิชา
  - ช่างอุตสาหกรรม: ช่างยนต์, ช่างกลโรงงาน, ช่างเชื่อมโลหะ, ช่างไฟฟ้ากำลัง, ช่างอิเล็กทรอนิกส์, เทคโนโลยีคอมพิวเตอร์, ช่างก่อสร้าง, โยธา, ช่างเทคนิคอุตสาหกรรม, เทคโนโลยีการผลิต (ทล.บ.)
  - พาณิชยกรรม: การบัญชี, เลขานุการ, การตลาด, เทคโนโลยีธุรกิจดิจิทัล
  - คหกรรม: คหกรรม
  - นักศึกษาแต่ละคนมีแผนกและ**ชั้นปี** (ปวช.1, ปวช.2, ปวช.3, ปวส.1, ปวส.2) เลือกในฟอร์มเพิ่ม/แก้ไขนักศึกษา
  - กรองตามแผนกหรือทั้งประเภทวิชาได้ในหน้านักศึกษา ลงชั่วโมงหลายคน และรายงาน, รายงานมีสรุปรายแผนก, CSV มีคอลัมน์แผนกและประเภทวิชา
  - เก็บในตาราง `fields` (ประเภทวิชา), `departments` (แผนก) และ `levels` (ชั้นปี) นักศึกษาอ้างอิงด้วย `users.department_id`, `users.level_id`
  - ผู้ดูแลเพิ่ม/แก้ไข/ลบ ประเภทวิชาและแผนกได้ในหน้า "แผนกวิชา" (ลบประเภทวิชาที่ยังมีแผนกไม่ได้)
- รายงาน: สรุปรายแผนก, สรุปรายชั้นปี, รายบุคคล, กรองเฉพาะผู้ค้าง, พิมพ์รายงาน, ส่งออก CSV
- ชั้นปี / ประเภทกิจกรรม: เพิ่ม (เช่น ทล.บ. ปี 1), **แก้ชื่อ**, ลบ, ดูจำนวนนักศึกษาและสถิติการใช้
- ผู้ใช้งานระบบ: เพิ่ม, **แก้ชื่อ/สิทธิ์**, รีเซ็ตรหัสผ่าน, ลบ
- ใช้งานบนมือถือได้

แบบฟอร์มสำหรับพิมพ์ (A4) มีข้อมูลนักศึกษา สาเหตุ จำนวนชั่วโมง ตารางกิจกรรมพร้อมช่องลงชื่อผู้ควบคุม และช่องลงชื่อนักศึกษา ครูที่ปรึกษา ผู้ปกครอง หัวหน้างานปกครอง เลือกพิมพ์แบบฟอร์มเปล่าได้

## วิธีรันในเครื่อง
1. เปิด XAMPP แล้ว Start MySQL (ผู้ใช้ root ไม่มีรหัสผ่าน)
2. (ไม่บังคับ) สร้างฐานข้อมูล `service_hours` (utf8mb4_unicode_ci) ใน phpMyAdmin ถ้าไม่สร้าง ระบบพยายามสร้างให้เอง
```
npm install
npm start
```
เปิด http://localhost:3000 · ผู้ดูแลเริ่มต้น `admin` / `admin123`
(ตั้งเอง: `$env:ADMIN_PASSWORD="รหัสใหม่"; npm start` ใน PowerShell ก่อนรันครั้งแรก)

ลำดับใช้งานครั้งแรก: ล็อกอิน admin → "ผู้ใช้งานระบบ" เพิ่มครู → "นักศึกษา" เพิ่มหรือนำเข้านักศึกษา (เลือกแผนก + ชั้นปี) · แผนกและชั้นปีมีให้แล้ว
นักศึกษาล็อกอินด้วยรหัสนักศึกษา รหัสผ่านเริ่มต้น = รหัสนักศึกษา (เปลี่ยนเองได้)

## ตัวแปรสภาพแวดล้อม
| ชื่อ | ความหมาย |
|---|---|
| PORT | พอร์ต (ค่าเริ่มต้น 3000) |
| DB_HOST / DB_PORT | ที่อยู่ MySQL (127.0.0.1 / 3306) |
| DB_USER / DB_PASSWORD | ผู้ใช้และรหัสผ่าน MySQL (root / ว่าง) |
| DB_NAME | ชื่อฐานข้อมูล (service_hours) |
| ADMIN_PASSWORD | รหัสผ่านผู้ดูแลตอนสร้างครั้งแรก |
| SESSION_SECRET | คีย์ session (สุ่มข้อความยาว ๆ ตอน deploy) |
| COOKIE_SECURE | ตั้งเป็น 1 เมื่อใช้ HTTPS |
| DB_SSL / DB_SSL_CA | ตั้ง DB_SSL=1 เมื่อฐานข้อมูลบังคับ SSL (เช่น Aiven) และใส่ใบรับรอง CA ใน DB_SSL_CA ได้ |
| SCHOOL_NAME | ชื่อสถานศึกษาที่แสดงบนเว็บและแบบฟอร์ม (ค่าเริ่มต้น วิทยาลัยเทคนิคชัยนาท) |

## ทดสอบบนเว็บฟรี: Render (รันโค้ด) + Aiven (ฐานข้อมูล MySQL)
Host ฟรีแบบ PHP (เช่น InfinityFree) รัน Node.js ไม่ได้ และไม่เปิดให้ต่อฐานข้อมูลจากที่อื่น จึงใช้ 2 บริการนี้คู่กัน
1. **Aiven** (aiven.io): สมัคร > Create service > **MySQL** > เลือก **Free plan** > รอจนสถานะ Running
   แล้วจดค่าจากหน้า Overview: Host, Port, User (`avnadmin`), Password, Database (`defaultdb`) และกดดาวน์โหลด **CA certificate**
2. **GitHub**: สร้าง repository ใหม่ > Add file > Upload files > ลากไฟล์ในโฟลเดอร์ `service-hours-node` ทั้งหมด (ยกเว้น `node_modules`) > Commit
3. **Render** (render.com): สมัครด้วย GitHub > New > **Web Service** > เลือก repository
   - Runtime: Node · Build Command: `npm install` · Start Command: `npm start` · Instance Type: **Free**
   - Environment Variables:

     | ชื่อ | ค่า |
     |---|---|
     | DB_HOST / DB_PORT | Host และ Port จาก Aiven |
     | DB_USER / DB_PASSWORD | `avnadmin` และรหัสผ่านจาก Aiven |
     | DB_NAME | `defaultdb` |
     | DB_SSL | `1` |
     | DB_SSL_CA | (ไม่บังคับ) เนื้อหาไฟล์ CA certificate ทั้งไฟล์ เพื่อตรวจใบรับรองแบบเต็ม |
     | SESSION_SECRET | ข้อความสุ่มยาว ๆ |
     | COOKIE_SECURE | `1` |
     | ADMIN_PASSWORD | รหัสผ่าน admin ที่ต้องการ (ใช้ตอนสร้างครั้งแรก) |
4. กด Create Web Service รอ Deploy เสร็จ จะได้ลิงก์ `https://ชื่อ.onrender.com` ตารางทั้ง 7 ตารางสร้างให้เองตอนเปิดครั้งแรก
5. แก้โค้ดทีหลัง: อัปโหลดไฟล์ใหม่ทับใน GitHub แล้ว Render จะ Deploy ใหม่ให้อัตโนมัติ

ข้อจำกัดแบบฟรี: Render หลับเมื่อไม่มีคนใช้ ~15 นาที เปิดครั้งแรกหลังหลับรอ ~1 นาที และผู้ใช้ต้องล็อกอินใหม่
ถ้ามีโดเมนของตัวเอง ใส่ได้ที่ Render > Settings > Custom Domains แล้วตั้ง CNAME ที่ผู้ให้บริการโดเมน

## นำขึ้นเว็บจริงแบบ cPanel (Host ที่มีเมนู "Setup Node.js App")
1. ซื้อ Host ที่รองรับ Node.js (ใน cPanel ต้องมีเมนู **Setup Node.js App**) และผูกโดเมน
2. cPanel > **MySQL Databases**: สร้างฐานข้อมูล, สร้างผู้ใช้, Add User To Database แล้วติ๊ก ALL PRIVILEGES
3. cPanel > **phpMyAdmin** > เลือกฐานข้อมูล > แท็บ **Import** > เลือก `docs/service_hours.sql` > Go
   (ข้ามข้อนี้ได้ ระบบสร้างตารางเองตอนเปิดครั้งแรก)
4. cPanel > **File Manager**: อัปโหลด zip โปรเจกต์ (ไม่ต้องมี node_modules) แล้ว Extract ไว้นอก public_html เช่น `/home/ชื่อผู้ใช้/service-hours-node`
5. cPanel > **Setup Node.js App** > Create Application
   - Node.js version: 18 ขึ้นไป · Application root: `service-hours-node` · Application URL: โดเมนของคุณ · Startup file: `server.js`
   - Environment variables: `DB_HOST`=localhost, `DB_NAME`, `DB_USER`, `DB_PASSWORD` (ตามข้อ 2), `SESSION_SECRET`=ข้อความสุ่มยาว ๆ, `COOKIE_SECURE`=1
6. กด **Run NPM Install** แล้วกด **Restart** เปิดโดเมนจะเห็นหน้าเข้าสู่ระบบ
7. cPanel > **SSL/TLS Status** เปิด HTTPS (AutoSSL) · ล็อกอิน admin / admin123 แล้วเปลี่ยนรหัสผ่านทันที

ถ้า Host มีแค่ PHP ไม่มีเมนู Setup Node.js App ระบบนี้รันไม่ได้ ต้องเปลี่ยนเป็น Host ที่รองรับ Node.js หรือ VPS ตามหัวข้อถัดไป

## นำขึ้นเว็บจริง (VPS + โดเมนของตัวเอง)
ต้องใช้ **VPS (Ubuntu)** หรือ Host ที่รองรับ Node.js และ MySQL (Host แบบ PHP ล้วนรันไม่ได้ ถามผู้ขายก่อนซื้อ)
1. เช่า VPS และจดโดเมน แล้วตั้ง A record ชี้ไป IP ของ VPS
2. ติดตั้ง Node.js, nginx, MySQL: `sudo apt update && sudo apt install -y nginx mysql-server`
3. สร้างฐานข้อมูลและผู้ใช้เฉพาะแอปใน MySQL
```
CREATE DATABASE service_hours CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'sh_app'@'localhost' IDENTIFIED BY 'รหัสผ่านยาวๆ';
GRANT ALL ON service_hours.* TO 'sh_app'@'localhost';
```
4. อัปโหลดโปรเจ็กต์ แล้ว `npm install --omit=dev`
5. รันด้วย pm2
`sudo npm i -g pm2`
`COOKIE_SECURE=1 SESSION_SECRET=ข้อความสุ่ม ADMIN_PASSWORD=รหัสผู้ดูแล DB_USER=sh_app DB_PASSWORD=รหัสผ่านฐานข้อมูล pm2 start server.js --name service-hours`
`pm2 save && pm2 startup`
6. ตั้ง nginx ส่งต่อไปพอร์ต 3000
```
server {
  server_name yourdomain.com;
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```
7. เปิด HTTPS: `sudo apt install -y certbot python3-certbot-nginx && sudo certbot --nginx -d yourdomain.com`
8. สำรองข้อมูล: `mysqldump -u sh_app -p service_hours > backup.sql`
